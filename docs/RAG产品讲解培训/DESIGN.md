# DESIGN.md · 《让工厂知识随问随答》RAG 产品讲解（20 页）

> 风格路由结果：场景 = 培训技术分享 / 产品讲解 → **不命中** academic / consulting / redgold 三个预设分支 → 走通用设计原则（universal-only），本文件即本项目设计宪法。
> 调性：科技蓝 · 明亮清晰 · 制造业专业 · 数据驱动。参照产品自身默认外观（蓝 + 明亮 + 清晰档）与用户偏好。

## 1. 画布与母版

- 画布：**1280 × 720**；页面 padding：上下 20px、左右 64px。
- **A · 标题块 0–120px**：主标题 34px bold（色 #0F172A），左对齐；标题下方 16px 副标/章节标签（#475569）。标题块右侧严禁装饰小图。
- **B · 内容区 120–660px**（540px 可用）：一切正文、卡片、SVG、图。
- **C · 页脚条 660–720px**：左侧「mfg-agent-platform · 独立开发实践分享」14px #94A3B8；右侧页码 `NN / 20` 14px #94A3B8（等宽字体）。
- 封面 / 章节扉页 / 结束页用自定义全幅版式，可省 C 区；其余 16 页母版严格一致。

## 2. 颜色系统（4 hex 色池 + 中性色）

| 角色 | Hex | 用途 |
| :--- | :--- | :--- |
| 主色（品牌蓝） | `#2563EB` | 标题强调、图表主系列、卡片头、链接性标注 |
| 辅色（青） | `#06B6D4` | 第二系列、SVG 链路第二层、渐变终点 |
| 强调色（橙） | `#F97316` | **仅焦点**：巨型数字、核心阈值标注、关键判断句 |
| 深色（墨） | `#0F172A` | 正文主色、深色蒙版、封面叠层 |

- 背景 `#FFFFFF`；浅卡片底 `#EFF6FF`（主色 8% 透明度视觉等效）、次级浅底 `#F1F5F9`；中性文本 `#475569` / `#94A3B8`。
- **色彩面积分配**：主色 ≤60%、辅色 ≤30%、强调 ≤10%（Hero 页 15–20%）、中性剩余。P08/P15 为强调色爆发页（15–20%），其余 supporting 页强调 ≤5%。
- **渐变方案**：主渐变 `linear-gradient(135deg, #2563EB 0%, #06B6D4 100%)` 用于封面蒙版、扉页大数字、卡片头；强调渐变 `linear-gradient(135deg, #F97316 0%, #FBBF24 100%)` 仅用于 P08/P15 巨型数字；深色蒙版 `rgba(15,23,42,0.55)`（扉页）/ `0.68`（封面、结束页）叠全幅图。
- **半透明策略**：`rgba(37,99,235,0.08)` 卡片底；`rgba(6,182,212,0.10)` 第二层卡片底；SVG 连线 `opacity 0.15–0.3` 底层装饰。

## 4. 密度与留白

- 内容页正文 ≥180 字；留白 ≤35%（P08/P15 hero 页 40–45%，围绕锚点数字）。
- 卡片填充率 ≥85%；同行兄弟卡「标题块/正文块/尾条」三段 y 轴等高对齐，尾条 `marginTop:'auto'` 钉底。
- 每页 ≥1 视觉锚点（≥44px 元素或 ≥40% B 区主视觉）。
